# Woodblock frame provenance

The Woodblock skin frame (`woodblock-wave-frame.jpg`) is a 1280×720 crop of a documented public-domain museum scan of Katsushika Hokusai's *Under the Wave off Kanagawa* (*Kanagawa oki nami ura*), also known as *The Great Wave*, from the series *Thirty-six Views of Mount Fuji* (*Fugaku sanjūrokkei*), ca. 1830–32.

The file in this folder was downloaded from the Met's published Open Access image URL on 25 November 2026 and cropped as described below. It replaces an earlier undocumented copy of the same print.

## Crop

The previous frame was 1280×720 (16:9). This file keeps those dimensions and the same composition: the great wave on the left, Mount Fuji in the lower center, the foreground boat at the bottom, and the right-hand foam, with the title cartouche and signature cropped out.

- Source crop window on DP130155.jpg: left 400, top 300, width 3459, height 1945 (flush with the right edge of the scan)
- Then resized to 1280×720

No color grading, watermark, or other alteration was applied beyond that crop and resize.
